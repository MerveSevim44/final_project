## 🚀 Quick Start (3 Steps)

### Step 1: Start Backend
```powershell
cd backend
python -m uvicorn main:app --reload
```

### Step 2: Open Frontend
```powershell
# Option A: Direct
start frontend/index.html

# Option B: Server
cd frontend
python -m http.server 8080
# Then open: http://localhost:8080
```

### Step 3: Use Application
1. Fill out the form
2. Click "🚀 Predict Grade"
3. View your prediction

## 🎓 Backend Information

### API Endpoint
- **URL**: `http://127.0.0.1:8000/predict`
- **Method**: POST
- **Input**: 32 student attributes (JSON)
- **Output**: Predicted final grade (G3)

### Input Fields (32 Total)
```
Personal (4):        school, sex, age, address
Family (8):          famsize, Pstatus, Medu, Fedu, Mjob, Fjob, reason, guardian
Academic (10):       traveltime, studytime, failures, schoolsup, famsup, 
                     paid, activities, absences, G1, G2
Lifestyle (6):       famrel, freetime, goout, Dalc, Walc, health
Aspirations (4):     nursery, higher, internet, romantic
```

### Grade Categories
- 🌟 **Excellent** (≥18): Outstanding
- ✨ **Very Good** (≥16): Great
- 👍 **Good** (≥14): On track
- 👌 **Fair** (≥12): Decent
- 📚 **Below Average** (≥10): Needs work
- ⚠️ **Poor** (<10): Requires help
